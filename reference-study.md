# Reference Study and Content Correction Notes

## Reference: Teaching For Development

The observed reference website uses a **single elevated navigation surface** with a clear logo, primary routes, a dark-mode control, and one explicit Khmer/English language link. Its home experience keeps the hero copy short: a compact subscriber context, two primary actions, one headline, one supporting sentence, and founder attribution. The useful ideas for Narin Phin’s portfolio are the visible language control, concise action-oriented hero, restrained navigation, social proof or credibility presented as short proof points, and content grouped into separate route families. The new work will adopt those principles while retaining a quieter scholarly aesthetic, original layout, Narin’s actual portrait, and a professional education-focused visual system. It will not replicate the reference’s photograph mosaic, brand language, dark-mode model, or page composition.

## Design Decisions for the Next Revision

The new header will use a compact bilingual language switch with a globe/language icon and a clearly labelled **ខ្មែរ / EN** state. The default English experience will become shorter and more visual, with career context and long-form content moved into progressive disclosure, concise cards, or intentional sub-routes. Khmer mode will translate the primary navigation, page labels, the hero and contact context first; English remains the authoritative detailed professional version until complete user-approved translations are supplied.

The motion system will retain Lenis only for desktop but reduce visual density: short fade-and-translate entrances, no heavy scroll storytelling, and a hero image system with a small collection of meaningful, deliberate visual frames rather than long text blocks.
