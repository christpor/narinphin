# Narin Phin — English Educator & Academic Leader

This repository contains the source code for **Narin Phin’s bilingual professional portfolio**. It presents more than three decades of work in English language education, academic leadership, curriculum development, teacher mentoring, and community learning in Phnom Penh, Cambodia.

## Live Portfolio

Visit the published website: **[narinfolio-lpqkrtgt.manus.space](https://narinfolio-lpqkrtgt.manus.space)**

## Project Highlights

| Area | Implementation |
| --- | --- |
| Languages | Khmer and English interface with a remembered language preference |
| Design | White-led editorial system using Kantumruy Pro, Source Serif 4, Instrument Sans, evergreen, ivory, and copper |
| Navigation | Responsive real routes for Home, About, Expertise, Journey, Learn, and Contact |
| Contact | Gmail enquiry action with a considered pre-filled message template |
| Accessibility | Keyboard-aware navigation, responsive layouts, reduced-motion support, and clear text contrast |
| Discovery | Per-route metadata, Open Graph tags, Twitter cards, JSON-LD, sitemap, robots policy, and static route prerendering |

## Local Development

```bash
pnpm install
pnpm dev
```

To create the static GitHub Pages build locally, run:

```bash
pnpm build:pages
```

## Stack

React 19, Vite, TypeScript, Wouter, Tailwind CSS, Framer Motion, and Lenis.
